Acme Store — demo site

This page simulates a customer website with the messenger widget embedded. It runs on port 5180 (separate from the agent app on 5173).

Setup

  1. Run API (npm run dev:server), Redis, and apply Supabase migrations.
  2. Create a widget installation (Settings → Web widget) or run node server/scripts/seed-widget-installation.js <orgId>
  3. Paste your widget_key below and reload.
